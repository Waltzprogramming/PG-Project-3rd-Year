# Paper Pinix

Paper Pinix is a 3D/2D graphic programming game project developed for a university Graphic Programming course. The project includes a Raylib-based main menu, multiple playable worlds, collectible objectives, level progression, character movement, camera systems, and custom game assets.

## Project Description

The goal of Paper Pinix is to present a playable multi-world adventure inspired by classic platform games. The player progresses through different worlds, collects coins, unlocks stars, and completes levels in order to advance through the game.

This repository documents the development process and contains the source code, assets, shaders, and runtime files required to build and run the project.

## Features

- Raylib main menu with world selection.
- Four playable worlds with progression logic.
- Locked and unlocked level flow.
- 2D and 3D gameplay perspectives.
- Collectible coins and level completion objectives.
- Custom player movement, camera behavior, collisions, HUD, and menus.
- Visual assets, audio, shaders, and 3D models integrated into the game.

## How to Run the Project

For the ready-to-play version, use the packaged executable folder:

1. Download or copy the `PG.zip` file.
2. Extract the ZIP file.
3. Open the extracted `Build/Bin`.
4. Run `Proyecto_PG.exe`.

Do not move the executable outside the folder, because it needs the included `assets`, `shaders`, `Menu`, and DLL files to work correctly.

## How to Build from Source

1. Open `Proyecto_PG.vcxproj` in Visual Studio 2022.
2. Select the `Release` configuration.
3. Select the `x64` platform.
4. Build the project.
5. The main executable will be generated in:


build/bin/Proyecto_PG.exe
